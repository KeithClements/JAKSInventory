Design rationale

  • Banded rows are gone. The v1 drawer rendered each field as a full-width white-bordered row, which created a striping effect that fought the dark theme. v2 uses a two-column key/value grid with no per-row borders.
  • Header is fixed. Title + SKU + close button always visible at the top, no scrolling required to dismiss.
  • Hero section surfaces the answer to "what is this?" — thumbnail, name, platform, status pills, vendor — at a glance.
  • Action bar below the hero exposes the operations users actually run (Edit / PO / Adjust / Photos), instead of forcing them back to the grid.
  • Collapsible sections let users hide noise. Stock and Pricing default open; everything else defaults closed.
  • Stock strip uses four small cards instead of a list — On Hand, Alloc, Avail, On PO — which is what users actually look at first.
  • Keyboard: Esc closes, Enter opens the full edit dialog.
  • Width: 420 px (was 380) — gives the two-column grid room to breathe.

If you'd rather remove the drawer entirely and double-click rows to open the full editor instead, that's also a clean option — the drawer's value is for quick scanning without leaving the grid. Up to you.
