What's broken right now

BUGRight detail panel is white

Drawer uses background:#fdfdfd; border:#d0d0d0 — leftover light theme. Text on white is illegible against the dark app.

FIXRe-skin the drawer: background:var(--panel), dark border, accent orange header, colored key/value rows. See "DETAIL DRAWER" sample below.

BUGActivity legend invisible

Legend renders but the Q / S / P / A / R / K letters take the global text color. Looks like flat white text — no legend semantics.

FIXForce setTextFormat(RichText) and inline colored spans; bump label to font-weight:900. Add a dashed top-border separator so it reads as a strip.

BUGKPI cards show "box around text"

The QLabel value field is inheriting a thin frame from the global theme stylesheet. Looks like every number sits in a recessed box.

FIXExplicitly set border:none;background:transparent on every label inside the card. Add a 3-px colored left bar (per-category accent) — matches the mockup.

BUGKPI cards do nothing on click

They're decorative. Mockup §4 calls for "drill-down" — clicking a KPI should filter the table to those rows.

FIXWrap each card in a clickable QFrame with mousePressEvent → render the matching subset (re-uses the existing _render_subset helper from the chip drill-down). Pointer cursor on hover.

BUGCheckbox column has weird artifact

Empty checkbox shows a black square / outline of the previous indicator — Qt's default dark-on-dark glyph fights the alternating row color.

FIXAdd explicit QTableWidget::indicator rules to the products QSS: 14×14, #4a5360 border, #1d242c background, orange when checked with a white ✓. No more ghost glyph.

BUGNo way to clear filters

Once a search + 2 combos are set there's no reset path other than emptying each one manually.

FIXAdd a "🧹 Clear" button on the right side of the filter row. Clears the search box and all 4 combos, then re-runs the search. Hidden when nothing is filtering (optional).
