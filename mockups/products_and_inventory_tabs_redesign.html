2 · Gap analysis — current Products vs target

Current Products screen

  • Fix Table has only SKU · Item · On Hand · Cost · List · Margin · Status
  • Fix No Type chip column (Reman / Kit / Core / New / Used)
  • Fix No Category column
  • Fix No Alloc / Avail split (the daily question: "can I sell it?")
  • Fix No Reorder point column
  • Fix No Vendor column
  • Fix No Avail progress bar — hard to spot stockout risk at a glance
  • Fix No Activity icons column (on quote / SO / PO / adjustment / kit)
  • Fix Item column wraps weirdly to a second line with stale data
  • Fix Big Product Detail panel hardcoded at bottom — duplicates row info, eats vertical space
  • Move AI buttons + "Scrape Selected" + "Columns" + "More" crowd the filter bar

Target (this mockup)

  • Keep 7 KPI cards across the top — already present, just restyled
  • New 14-column table with Type chip, Avail bar, Vendor, Activity icons
  • New Needs-attention chip row — clickable filters for the 7 most common product-hygiene problems
  • New Header buttons: Import CSV · Export · Print Labels · AI Catalog Import · + New Product (orange CTA)
  • New Filter row condensed to: Search · 5 dropdowns · View/Edit · Cycle Count · Create PO · Bulk Edit
  • Move Product Detail panel → opens as a right-side slide-over on row click (not always-on)
  • Move Scrape Selected / Columns / More → tucked into a "More ▾" overflow button
  • Keep Status pill (In Stock / Low / Out / On Order), now color-coded properly
3 · Inventory tabs — current vs proposed

Current (9 tabs)

  • OverviewDropDuplicates Dashboard. Forces an extra click before users reach Products.
  • ProductsKeepAlready the default landing — the SKU master.
  • PricingDemoteDaily users don't bulk-edit pricing. Make it a button on Products → opens Pricing Lists / Maintenance / Tiered as a drawer.
  • AdjustmentsKeepManual qty + cost adjustments — daily workflow.
  • LocationsRename→ Warehouses & Bins. Locations is ambiguous (warehouse? bin? row?).
  • KitsKeepBundle / assembly definitions.
  • Bulk ImportDemoteNot a "place" — it's a one-shot workflow. Live as a button on Products header.
  • CoresMoveCore processing is a sales-side workflow (returns / refund credit). Belongs under Sales → Cores or the Customer Profile.
  • AuditRename→ Cycle Counts. "Audit" is vague; cycle counting is the actual operational concept.

Proposed (6 tabs)

  • ProductsKeepNow lands here by default with the new 14-column layout above.
  • AdjustmentsKeepUnchanged.
  • Warehouses & BinsRenamedWarehouse hierarchy + bin slotting + zone heatmap.
  • KitsKeepUnchanged.
  • Cycle CountsRenamedScheduled counts + variance dashboard. Replaces "Audit".
  • Categories & BrandsNewTaxonomy management — today buried in Settings and dropdowns. Should be first-class.

4 · Additional suggestions for Inventory

Worth considering (medium effort)

  • Idea Stock Movements ledger — read-only timeline of every qty/cost change per SKU (receipt, sale, adjustment, kit build, transfer). Reachable from each row, no top-level tab needed.
  • Idea Saved views on Products — "My low-stock list", "AI-enriched needs review", "Negative on-hand". Saved per-user.
  • Idea Right-side slide-over detail instead of always-on bottom panel. Click row → 420 px drawer with photo, OEM cross-refs, supplier history, last 10 sales, on-quotes.
  • Idea Reorder simulator button next to "Create PO" — picks vendor, fills qty using velocity × lead time × safety factor; one click sends to PO draft.
  • Idea Photo / cross-ref completeness as a passive nudge — when "Missing photo (12)" chip is clicked, jump into a focused single-screen wizard, not the full grid.

Worth considering (small effort, big payoff)

  • Idea Density toggle (Compact / Comfortable) in the More menu. Today's row height eats screen real estate.
  • Idea Right-click row menu — Edit · Duplicate · Adjust qty · Create PO line · Add to active quote · Mark dead.
  • Idea Sticky filter bar + sticky table header on scroll.
  • Idea Last-edited stamp on row hover ("edited 2h ago by Keith").
  • Idea Bulk Edit opens a modal with a column picker — not the current full-table inline edit which is dangerous.
  • Idea Move "AI · Find missing data" and "AI · Suggest reorders" into the gear menu under Tools → AI helpers — keep the Products header for the 4 most-used buttons only.
5 · Implementation order (if approved)
  1. Sub-tab cleanup — drop Overview, demote Bulk Import to header button, move Cores out, rename Audit→Cycle Counts, Locations→Warehouses & Bins, add Categories & Brands placeholder.
  2. Products table columns — add Type chip, Category, Alloc, Avail bar, Reorder, Vendor, Activity icons. Hide the existing always-on detail panel; reuse it as a slide-over.
  3. Needs-attention chip row — wire the 7 chips to existing filters (most already exist as flags).
  4. Header buttons polish — keep Import CSV · Export · Print Labels · AI Catalog Import · + New Product visible; move others to overflow.
  5. Activity icons — compute from the same data the bulk-flag query already returns; just render them in the last column.
  6. Slide-over detail — port the existing detail panel into a drawer triggered by row click + a close button.
