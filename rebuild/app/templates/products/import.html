Catalog Utilities

Derive manufacturers from descriptions

Fills the blank Manufacturer field on existing products from what's already stored — OEM reference brands, applications, title, keywords. One clear make wins; multi-make parts stay blank; never overwrites a manufacturer you set by hand.

{# §23.3 Phase 1 #5 — re-sweep the catalog with the CURRENT classification rules; only fills a still-blank category/engine make/engine model, same "never overwrite a confirmed value" contract as the utility above. #}

Re-classify with current rules

Re-runs category + engine make/model detection across every product still missing one, using today's classification rules (they improve after products were first imported). Only fills blanks; never overwrites a category or engine make/model you (or a prior import) already set.

{# Reorder-point backfill by category — makes the Low-Stock/Reorder tab real. Fills only reorder_point=0 products under the picked category (subcategories included); a deliberately-set value is never touched. #}

Set reorder points by category

Applies the value to every active product under the chosen category (subcategories included) that still has a reorder point of 0 — never overwrites a reorder point someone already set. Products at or below their reorder point surface on the Low-Stock tab and the reorder report.
